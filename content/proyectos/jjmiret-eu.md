## Qué es

El primer proyecto de la lista es el que estás leyendo. Al fin y al cabo, montar una web personal también es un proyecto.

Es un sitio estático donde reúno el blog, los proyectos, el currículum y mis redes sociales. Anteriormente tenía una página en Carrd, anteriormente una página estática en un VPS, anteriormente un WordPress, anteriormente un Blogger, anteriormente...

## Cómo está hecho

- [Hugo](https://gohugo.io/) genera el sitio a partir de ficheros Markdown.
- [PaperMod](https://github.com/adityatelange/hugo-PaperMod) es el tema base, con una capa de CSS propia por encima.
- GitHub Actions construye el sitio en cada cambio en el repositorio de [jjmiret.eu](https://github.com/jjmiret/jjmiret.eu) y lo publica en GitHub Pages.

No se usan ni servicios de analítica ni rastreadores de ningún tipo. Es una página como las que se hacían en tiempos de Microsoft FrontPage, pero sin marquesinas y mucho más bonita.

Para adaptar la web he hecho *vibe coding* con [Claude](https://claude.ai/): el diseño, la configuración y el endurecimiento de seguridad salieron de ahí. El contenido, lo escribo yo.
